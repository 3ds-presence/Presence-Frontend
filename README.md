# Presence-3DS Frontend
This project is part of the [Presence-3DS](https://github.com/3ds-presence/) project.

This repo contains the frontend of Presence-3DS, along with all the 3DS games logos. 
It connects to the backend API to handle Discord authentication and configuration download.

## Contribution
You can contribute to this project by adding new 3DS games logos.
Logos must be in PNG format, and must be in a folder named after the game ID, and the logo file must be named `logo.png`.
